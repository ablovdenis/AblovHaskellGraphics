Как включать:

Находясь внутри папки проекта, пропишите "cabal run". Должно открыться окно с автоматической загрузкой файла "Hare.txt".

Чтоб загрузить другой файл, нажмите ЛКМ кнопку в правом верхнем углу окна, после чего в терминале появится приглашение написать название файла с расширением (".txt") (файлы загружаются из папки "Files/" !). Вписываете название нужного Вам файла и нажимаете "Enter" для выполнения загрузки.
